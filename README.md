# Le Beauty Bar

Luxury beauty and wellness website built from the approved Le Beauty Bar visual direction.

## Files
- index.html — complete page
- styles.css — responsive styling and brand system
- script.js — mobile navigation + booking modal/WhatsApp flow

## Before launch
1. Replace the demo WhatsApp number in `script.js`.
2. Replace the placeholder address, phone, hours and social links in `index.html`.
3. Replace the stock image URLs with the salon's real gallery/photos.
4. Add the final service pricing if desired.
5. Deploy to Vercel, Netlify, GitHub Pages, or any static hosting.
